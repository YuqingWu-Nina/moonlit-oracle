# Moonlit Oracle

A self-contained, three-card tarot reading demo. It draws cards locally and creates a reflective reading for career, love, and well-being without external services.

## Run locally

Open `index.html` directly in a modern browser, or run:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

The readings are for entertainment only and are not professional advice.
